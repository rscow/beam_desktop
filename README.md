# Beam Designer

Beam Designer is a Python/Tkinter desktop app that calculates beam reactions,
shear, moment, deflection, and bending utilization, displays the diagrams, and
exports designs and calculation results.

## Install

Install Python 3 with Tkinter. No `pip` packages are required. On Ubuntu or
Debian, install the system packages with:

```bash
sudo apt install python3 python3-tk
```

## Start

From this project directory, run:

```bash
python3 main.py
```
